# AdigunBible

**One edition. Scripture in a new generation's language.**

AdigunBible is the original Gen Z Bible edition by Hephzibah Behulah Evangelism. Its verse-by-verse writing uses energetic Gen Z language, slang, expressive punctuation, and emojis throughout while preserving the meaning and flow of each verse. The Gen Z Bible website is a style reference; AdigunBible uses original wording.
